# Dancing Mice - Two Player Dance Party! 🐭💃🕺

A fun two-player pygame where adorable mice dance together in a colorful, animated world!

## Features

- **Two adorable animated mice** with smooth movements and cute designs
- **Multiple dance moves** including spinning and jumping
- **Colorful particle effects** when dancing
- **Trail effects** that follow the mice as they move
- **Beautiful animated background** with twinkling stars
- **Two-player cooperative gameplay** - dance together with a friend!

## Installation

1. Make sure you have Python 3.7+ installed
2. Install the required dependencies:

```bash
pip install -r requirements.txt
```

## How to Run

Simply run the game script:

```bash
python dancing_mice.py
```

Or make it executable and run directly:

```bash
chmod +x dancing_mice.py
./dancing_mice.py
```

## Controls

### Player 1 (Blue Mouse)
- **W/A/S/D** - Move up/left/down/right
- **Q** - Spin dance (rainbow effect!)
- **E** - Jump dance

### Player 2 (Pink Mouse)
- **Arrow Keys** - Move in four directions
- **Right Shift** - Spin dance (rainbow effect!)
- **Left Shift** - Jump dance

### General
- **ESC** - Quit the game

## Gameplay Tips

- Move around the screen and explore the dance floor
- Try spinning while moving to create beautiful rainbow trails
- Jump at the same time as your friend for synchronized dancing
- Experiment with combining different moves
- Get close to each other and dance together!

## Game Features Explained

- **Spin Dance**: Hold the spin button to make your mouse rotate with a mesmerizing rainbow color effect
- **Jump Dance**: Press the jump button to make your mouse bounce into the air with gravity physics
- **Particle Effects**: Colorful sparkles appear around your mouse while dancing
- **Trail System**: A glowing trail follows your mouse's movements
- **Animated Background**: Twinkling stars create a party atmosphere

## Technical Details

- Built with Python and Pygame
- Runs at 60 FPS for smooth animation
- Resolution: 1000x700 pixels
- Features custom particle systems and animation states
